Hero Story Generator

A Java console-based story generator that lets users create their own hero stories.

How It Works

The user:

1. Chooses a story genre
2. Chooses a story
3. Creates their hero
4. Enters a companion, weapon, villain, power, creature, location, and relic
5. Gets a custom-generated story based on their choices

Features

- 15 different genres
- 15 stories per genre
- 225 possible story templates
- Custom hero creation
- Custom characters, weapons, powers, creatures, and locations
- Console-based interface
- Uses Java `String.format()` to generate stories

Genres

- Sci-Fi Adventure
- Ninja/Samurai
- Mythology

- Pirate Adventure
- Detective/Crime
- Comedy/Slapstick
- Romance
- Horror
- Sci-Fi Thriller
- Fantasy Romance
